WallpaperLive

Bring your own live wallpapers. WallpaperLive applies and plays local files you provide; it does not offer a wallpaper catalog, marketplace or download service. Obtain compatible media separately, save it on your PC, then import it into the app. Wallpapers shown in screenshots are examples, not included downloads. Any Setup download described below is the native decoder, not a wallpaper.

The Library's Where to find wallpapers menu opens mylivewallpapers.com, moewalls.com, motionbgs.com or www.desktophut.com in your browser. Settings links to the separate LiveBar product at https://livebar.vercel.app. WallpaperLive does not host or download their media and does not endorse their content or safety. Check each creator's license and import only compatible media you have permission to use.

Install WallpaperLive for your Windows user. No administrator rights are requested. Setup adds a Start menu shortcut, uninstall entry, and an option to launch the app on finish; it does not start a wallpaper, change the desktop, or enable automatic startup.

First installation needs a native decoder. Setup reuses matching existing decoder bytes without a download prompt. It also accepts the pinned upstream archive named mpv-dev.7z beside this installer for offline preparation. Otherwise, with your explicit consent, Setup downloads approximately 31.8 MB from the pinned 20261107 GitHub release. SHA256 is verified for both archive and extracted DLL; only libmpv-2.dll (about 121.6 MB) is installed. Different existing bytes are left untouched. Download failure, checksum failure or cancellation stops preparation before application files are installed.

The installer is unsigned. Use only trusted local media: the native decoder runs with your user privileges and is not a sandbox. Do not disable security controls or run as administrator to bypass a warning.

After installation, open WallpaperLive from the Start menu, import a file and apply it to one display or All displays. Applying to one display keeps the others playing. Fullscreen/maximized pause is independent per display; manual Pause/Resume and Stop affect all displays. Sound uses at most one stream. Each display has its own decoder, so memory and GPU use can increase; frame-perfect synchronization is not guaranteed. Cache preparation uses one worker across all displays. Upgrading retains previous single-display assignments without expanding them to All displays. Automatic startup stays opt-in within the app. Each new app process makes one background HTTPS request to api.github.com for the latest stable WallpaperLive release; its User-Agent includes the app version, never media paths or preferences. A newer release can show a tray notification; clicking opens its GitHub release page. No update is downloaded or installed automatically. User media and preferences are not removed by Setup. Copyright and decoder license notices are included in THIRD_PARTY.md.
