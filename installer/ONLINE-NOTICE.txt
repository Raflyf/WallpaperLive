WallpaperLive

Install WallpaperLive for your Windows user. No administrator rights are requested. Setup adds a Start menu shortcut and uninstall entry; it does not launch the app, start a wallpaper, change the desktop, or enable automatic startup.

Internet is required once. With your explicit consent, Setup downloads approximately 31.8 MB of native libmpv decoder files from the pinned 20261107 GitHub release, verifies SHA256 for both the archive and extracted DLL, and installs only libmpv-2.dll (about 121.6 MB). Matching existing decoder bytes are reused. Different existing bytes are left untouched. Download failure, checksum failure, or cancellation stops preparation before application files are installed.

The installer is unsigned. Use only trusted local media: the native decoder runs with your user privileges and is not a sandbox. Do not disable security controls or run as administrator to bypass a warning.

After installation, open WallpaperLive from the Start menu, choose a file and monitor, and apply it. Automatic startup stays opt-in within the app. User media and preferences are not removed by Setup. Copyright and decoder license notices are included in THIRD_PARTY.md.
